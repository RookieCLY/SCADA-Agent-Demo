**本周工作总结（06/15 - 06/20）**

本周（06/15 - 06/20）主要聚焦于 Agent 架构的工具挂载能力优化、新模型接入，以及相关实验脚本和分析工具的完善，为后续的消融实验做准备。

工程侧完成了基于 `tool_count` 动态挂载工具的核心逻辑，并成功接入并测试了 GLM（智谱）系列模型。
实验侧推进了 Experiment 2 (Tool count sweep) 及其它批量评估，并开发了新的 Trace 处理和进度监控脚本。
质量保障方面，针对工具注册表分发和 LLM 配置新增了单元测试。

**具体改动**

1. **核心架构优化 (Agent Core)**
   - **动态工具暴露**：重构了 `tool_registry.py`，实现了根据实验设定的 `tool_count` 参数，动态地向 LLM 暴露不同数量的可用工具。
   - **LLM 模块更新**：对 `agent/llm.py` 进行了较多结构优化和逻辑调整，但是不涉及主要逻辑。

2. **新模型接入与测试 (Model Integration)**
   - **GLM 接入**：新增了对智谱 GLM 模型的支持配置 （实际实验中并未使用）。


3. **实验进度与辅助脚本 (Experiments & Tooling)**
   - **实验追踪**：新增了 `scripts/watch_progress.py` 用于实时可视化监控跑批实验的进度。
   - **数据过滤**：新增 `scripts/filter_traces.py` 用于自动化清洗和过滤生成的 traces 日志。
   - **实验跑批**：推进了 Experiment 2（MIMO tool count sweep）与 Experiment 3 的开发与执行；完成了 Phase 4 (包含 DeepSeek 等模型) 批处理任务的更新，输出了最新结果。

4. **测试与依赖 (Testing)**
   - 新增 `tests/test_registry_dispatcher.py`，保障工具分发机制的正确性。
   - 新增 `tests/test_config_llm.py`，保障模型配置文件的加载行为符合预期。
